# 인던 룸

```
[인던 룸] 파티 4명 (여유 시 8명)
  - 일반 방 10~18 + 특수 몬스터 1~2
  - 서버 권위 인스턴스, 클리어 후 파괴
```

- 권장 1차 방 수·시간과 솔로 구성: [솔로 던전 구성](solo-dungeon.md)
- 실패 시 체크포인트: [체크포인트](checkpoint.md)
- 데미지·스폰·클리어 판정이 서버인 이유와 틱: [서버 권한](../network/authority.md)
- 룸당 프로세스/워커 또는 룸 매니저 내 격리. 4~8인, 수명 짧음. 런타임은 [Node](../tech/node.md)
- 클리어 후 Reward Service → DB. [아키텍처](../tech/architecture.md)
- 1차: 파티 **4인**, 던전 **1**. 8인 레이드 완성도는 1차 제외. [1차 출시 단위](../concept/mvp.md)
- 월드 범위: [범위](../concept/scope.md)
