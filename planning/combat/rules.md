# 전투 규칙

## 일반 방 원칙

- “한 컷에 끝나는 액션 쇼츠”
- 패턴 숙련형 금지 (특수몹 전용)
- 파티원 이펙트는 다운스케일, **내 캐릭터·타겟** 연출 우선

비트: [일반 방 비트](normal-room-beats.md), [특수 방 비트](special-room-beats.md)

파티원 이펙트 비율(High 100% / Low 30%)은 [연출](../art/presentation.md).

이동·스킬 요청은 클라, 히트·사망·클리어는 서버. [서버 권한](../network/authority.md)

스테이지 편성의 입력 규칙(한 클립에 주 입력 하나, 입력 1~2개)은 [던전 편성](../stage/lineup.md).
