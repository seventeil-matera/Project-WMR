# 특수 방 비트

목표 전투 **60~90초**는 [솔로 던전 구성](solo-dungeon.md). 한 줄 정의의 “약 90초”는 [방향](../concept/direction.md). 일반 방은 [일반 방 비트](normal-room-beats.md).

## 초안 (≈ 90초)

| 구간 | 내용 |
|------|------|
| 오프닝 ~5초 | 등장·카메라·티어 과시 |
| 페이즈 1 ~35초 | 기본 패턴 2~3개 |
| 페이즈 전환 | 파괴·각성 FX (성장 티어가 돋보이는 구간) |
| 페이즈 2 ~40초 | 강화 패턴 + 파티 역할 한 가지 |
| 처형 ~5초 | 긴 처치 연출 + 보상/티어업 티저 |

티어가 돋보이는 구간은 [성장 티어](../character/growth-tiers.md), 연출 예산은 [연출](../art/presentation.md).

## 프로토타입 v0 — 균열의 수호자 (목표 ~90초)

| 구간 | 내용 |
|------|------|
| 오프닝 | 가디언 1 + 애드 4 |
| 페이즈 1 | 가디언 HP > 45% |
| 전환 | HP 45% 이하 → `phase: 2` + 애드 6 추가 스폰 |
| 처치 | 전멸 시 `run_clear` |

`phase` / `run_clear`: [프로토콜 v0](../network/protocol-v0.md)
