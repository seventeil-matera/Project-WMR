# 일반 방 비트

목표 클리어 시간 **10~15초**와 방 개수는 [솔로 던전 구성](solo-dungeon.md). 특수 방은 [특수 방 비트](special-room-beats.md). 원칙은 [전투 규칙](rules.md).

## 초안 (한 클립 ≈ 12초)

| 초 | 비트 |
|----|------|
| 0.0~0.5 | 방 진입 / 카메라 고정 |
| 0.5~2.0 | 몬스터 스폰 + 짧은 위협 연출 |
| 2.0~10 | 광역·연계로 정리 (패턴 학습 최소화) |
| 10~12 | 처치 FX → 드롭 연출 → 다음 방 문 오픈 |
| 12~14 | 이동(가능하면 자동 런인 / 짧은 대시) |

## 프로토타입 v0 (목표 10~15초)

| 초 | 서버 | 클라 연출 |
|----|------|-----------|
| 0.0 | 방 스폰, 플레이어 좌측 배치 | 아레나 페이드/그리드 |
| 0.0~2.0 | 몬스터 우측 스폰 후 접근 | 스폰 이벤트 |
| 2.0~12 | 자동 평타 + Q/E | 히트 버스트, 카메라 쉐이크 |
| 클리어 | `room_clear` → 0.3~0.9초 전환 | 그린 링 FX |
| 전환 후 | 다음 방 `spawn` | 즉시 다음 클립 |

티어 업: 방 4/8/12 클리어 시 `tier_up` (T2/T3/T4). 성장 규칙: [성장 티어](../character/growth-tiers.md). 이벤트 이름: [프로토콜 v0](../network/protocol-v0.md)
