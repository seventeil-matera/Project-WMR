# 방향 (초안)

> 작업 제목: **Mortgage** (가칭)  
> 목표: PC 브라우저 우선 웹 MORPG. 쇼츠형 빠른 전투 + 성장 비주얼 업.

## 한 줄 정의

로비에서 모여 파티를 맺고, 던전에 들어가 **10~15초짜리 전투 클립을 10~20회** 이어 플레이하며, 특수 몬스터만 **약 90초** 하이라이트로 싸우는 **비주얼 액션 인스턴스 MORPG**.

- 로비에서 하는 일: [로비 샤드](../lobby/shard.md)
- 세션을 나누는 범위: [범위](scope.md)
- 방 수·목표 시간(일반 10~15초, 특수 60~90초): [솔로 던전 구성](../combat/solo-dungeon.md)

## 핵심 기둥 (Pillars)

| 기둥 | 플레이 체감 | 제작 규칙 |
|------|-------------|-----------|
| 빠른 템포 | 매칭→클리어→보상→재입장이 끊기지 않음 | 한 던전 체감 5~10분, 방 전환 공백 최소화 |
| 성장 비주얼 업 | 세면 캐릭터가 “달라 보임” | 스탯보다 **외형/오라/스킬 FX 티어**를 먼저 |
| 비주얼 액션 | 타격·처치 연출이 보상 | 일반전은 짧은 한 컷, 특수몹에 연출 예산 몰기 |
| Windows 웹 최적화 | Chrome/Edge 데스크톱 60fps | 품질 프리셋 Low/High, 이펙트 캡 |
| 모바일(후순위) | 작은 화면으로도 조작 가능 | 1차는 UI·입력만, 연출/해상도는 PC 기준 축소 |

- 성장과 비주얼을 나누는 결정: [성장 티어](../character/growth-tiers.md). 외형 표: [비주얼 티어](../art/visual-tiers.md)
- 짧은 한 컷·연출 예산·품질 프리셋 수치: [연출](../art/presentation.md)
- UI·입력: [UI·입력·오디오](../tech/ui-input-audio.md)
