# 서버 권한

- **서버 권위** 전투. 데미지·스폰·클리어 판정은 서버.
- v0 문장(데미지·사망·방 클리어·티어는 서버만, 클라는 연출만): [프로토콜 v0](protocol-v0.md)
- 인던의 서버 권위·클리어 후 파괴: [인던 룸](../combat/instance.md)

## 틱 / 동기화

| 구간 | 서버 틱 | 클라 |
|------|---------|------|
| 로비 | 5~10 Hz 또는 이벤트 드리븐 | 보간 거의 불필요 |
| 일반 방 | 15~20 Hz | 입력 전송 + 스냅샷 보간 |
| 특수몹 | 20 Hz | 동일 + 연출은 클라 예측(이펙트만) |

로비 샤드(전투 없음 → 낮은 틱): [로비 샤드](../lobby/shard.md)

v0 `snapshot`은 20Hz로 적혀 있다. [프로토콜 v0](protocol-v0.md)

## 원칙

- 이동·스킬 **요청은 클라**, **히트·사망·클리어는 서버**. 전투 원칙: [전투 규칙](../combat/rules.md)
- 이펙트·히트스톱·카메라 셰이크는 클라 전용 (서버는 “이벤트 타입”만 통지). 프리셋 수치: [연출](../art/presentation.md)
- 일반 15초 방은 동기화 오차가 쌓일 시간이 짧아 웹에 유리. 목표 시간: [솔로 던전 구성](../combat/solo-dungeon.md)
