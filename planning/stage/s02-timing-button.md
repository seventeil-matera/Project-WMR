# S02. 타이밍 맞춰 버튼 누르기

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 판정 구간에 맞춰 스킬/확인 키를 누름 (QTE·패리 계열) |
| 체감 | 짧은 긴장 → 성공 시 강한 히트스톱/처형 FX |
| 쇼츠 길이 | 8~12초 (한두 번의 판정으로 끝나는 클립) |
| 입력 | 단일 키(또는 스킬 슬롯) 타이밍 |
| 성공 | Perfect / Good 판정으로 피해·클리어 |
| 실패 | Miss 시 경직·데미지 또는 클립 실패 |
| 비주얼 업 | Perfect 연출이 티어 FX 과시 구간 |
| 주의 | 파티면 전원 동시 QTE vs 대표 1인 — 설계 선택 필요 |
| 우선순위 감 | 중 (구현 단순, 연출 의존도 높음) |

가드 타이밍(S08)과 입력이 비슷하다. [S08](s08-guard-timing.md)

파티 판정을 개인으로 할지 공유 게이지로 할지는 아직 안 함. [다음에 정하면 좋은 것](open-questions.md)
