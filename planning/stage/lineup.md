# 던전 편성 스케치 (미확정)

쇼츠 런 한 판(예: 12+1)에 섞는 예시. 권장 1차 숫자(일반 12 + 특수 1)는 [솔로 던전 구성](../combat/solo-dungeon.md).

| 슬롯 | 타입 후보 |
|------|-----------|
| 1~3 | [S07](s07-target-lock.md) 또는 가벼운 [S01](s01-danmaku.md) |
| 4 | [S02](s02-timing-button.md) 또는 [S11](s11-rhythm-tap.md) |
| 5~6 | [S01](s01-danmaku.md) |
| 7 | [S06](s06-dash.md) 또는 [S05](s05-hold-release.md) |
| 8 | [S03](s03-direction-gesture.md) 또는 [S09](s09-drag-path.md) |
| 9~10 | [S01](s01-danmaku.md) / [S07](s07-target-lock.md) |
| 11 | [S04](s04-button-mash.md) 또는 [S13](s13-stopwatch.md) |
| 12 | [S10](s10-choice.md) 또는 [S14](s14-knockback.md) |
| 13 특수 | [S01](s01-danmaku.md) 탄막 + [S08](s08-guard-timing.md)/[S02](s02-timing-button.md) 페이즈 |

역할로 묶은 표: [역할 묶음](roles.md)

규칙 초안:

- 한 클립 = **한 가지 주 입력** (섞어도 메인은 하나). 전투 쪽 원칙: [전투 규칙](../combat/rules.md)
- 실패해도 가능하면 **체크포인트 재도전** (쇼츠 템포 유지). [체크포인트](../combat/checkpoint.md)
- 연출 예산은 하이라이트·특수에 몰고, 메인·브레이크는 가볍고 자주. [연출](../art/presentation.md)
- 입력 종류는 클립당 **1~2개**, 3초 안에 규칙 이해
