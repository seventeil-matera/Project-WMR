# S04. 버튼 연타하기

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 제한 시간 안 연타로 게이지/제압 |
| 체감 | 단순·즉각적, 중간 템포 브레이크용 |
| 쇼츠 길이 | 6~10초 |
| 입력 | 동일 키 연타 (또는 좌클릭 연타) |
| 성공 | 게이지 full → 제압/파괴 |
| 실패 | 시간 초과·게이지 미달 |
| 비주얼 업 | 게이지·충격파가 티어색으로 물듦 |
| 주의 | 연타 피로 → 짧은 구간만, 대체 홀드 옵션(S05) 검토 |
| 우선순위 감 | 중저 (양산 쉽지만 남발하면 허무) |
