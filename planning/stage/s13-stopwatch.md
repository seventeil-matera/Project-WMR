# S13. 스탑워치형 스톱

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 차오르는 게이지에서 멈춘 위치가 점수/배율 |
| 체감 | 도박성 긴장 + 배율 폭발 |
| 쇼츠 길이 | 5~8초 |
| 입력 | 스톱 키 1회 |
| 성공 | 고배율 구간 정지 → 강화 일격 |
| 실패 | 배율 낮음 / 레드존 |
| 비주얼 업 | 게이지 색·폭발 규모가 티어 연동 |
| 주의 | 순수 랜덤처럼 보이면 불만 → 읽을 수 있는 스위트 존 |
| 우선순위 감 | 중 |
