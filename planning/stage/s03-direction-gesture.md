# S03. 타이밍 맞춰 좌·우·위·아래 제스처

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 지시 방향에 맞춰 스와이프/키 방향 입력 |
| 체감 | 리듬 게임형 회피·가드·반격 |
| 쇼츠 길이 | 10~15초, 노트 4~8개 |
| 입력 | ← → ↑ ↓ (키보드) / 스와이프(모바일 대비) |
| 성공 | 시퀀스 통과 → 반격 일격 클리어 |
| 실패 | 잘못된 방향·늦은 입력 |
| 비주얼 업 | 방향 성공마다 짧은 컷인, 마지막에 티어 피니시 |
| 주의 | PC·모바일 입력 매핑을 처음부터 같이 정의 |
| 우선순위 감 | 중 (모바일 “작은 화면” 목표와 궁합) |

모바일은 1차에서 UI·입력만. [방향](../concept/direction.md), [UI·입력·오디오](../tech/ui-input-audio.md)
