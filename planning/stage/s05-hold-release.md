# S05. 홀드 차지 릴리즈

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 길게 누르다 놓을 타이밍만으로 일격 |
| 체감 | 긴장 → 릴리즈 순간 화면 가득 연출 |
| 쇼츠 길이 | 6~12초 |
| 입력 | 홀드 → 릴리즈 (한 키) |
| 성공 | 스위트 스팟 릴리즈 → 풀 피니시 |
| 실패 | 너무 이르거나 늦음 → 약타/경직 |
| 비주얼 업 | 차지 오라가 티어색, 릴리즈 시 티어 FX 폭발 |
| 주의 | UI 게이지가 화면을 가리지 않게 |
| 우선순위 감 | 높음 |

연타(S04)의 대체 옵션으로 적혀 있다. [S04](s04-button-mash.md)
