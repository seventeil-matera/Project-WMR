# S10. 둘 중 하나 선택

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 좌/우 카드·문·약점 중 하나를 고르면 즉시 분기 연출 |
| 체감 | 생각 0.5초 → 결과 클립 |
| 쇼츠 길이 | 5~10초 |
| 입력 | 좌/우 키 또는 클릭 1회 |
| 성공 | 올바른/더 유리한 선택 → 강한 클리어 연출 |
| 실패 | 함정 선택 → 짧은 페널티 후 재도전 또는 약클리어 |
| 비주얼 업 | 선택지 아이콘·결과 FX에 티어 반영 |
| 주의 | “정답”이 너무 숨겨지면 쇼츠 템포 붕괴 → 힌트 명확히 |
| 우선순위 감 | 중 (템포 브레이크·스토리 비트용) |

재도전은 가능하면 체크포인트. [체크포인트](../combat/checkpoint.md)

티어 반영: [비주얼 티어](../art/visual-tiers.md)
