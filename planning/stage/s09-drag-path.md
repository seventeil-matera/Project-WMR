# S09. 드래그로 궤적

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 짧은 곡선을 그리면 검기/레이저가 그 길을 관통 |
| 체감 | “내가 궤적을 그렸다”는 소유감 + 관통 연출 |
| 쇼츠 길이 | 8~14초 |
| 입력 | 마우스 드래그 / 터치 스와이프 곡선 |
| 성공 | 궤적이 적을 충분히 스침 → 처치 |
| 실패 | 빗나감·시간 초과 |
| 비주얼 업 | 궤적 선이 티어 그라데이션 |
| 주의 | PC·모바일 입력 편차, 부정 궤적(너무 긴 선) 제한 |
| 우선순위 감 | 중~높음 |

입력 우선순위: [UI·입력·오디오](../tech/ui-input-audio.md). 모바일 드래그 UX는 아직 안 함. [다음에 정하면 좋은 것](open-questions.md)

티어 그라데이션: [비주얼 티어](../art/visual-tiers.md)
