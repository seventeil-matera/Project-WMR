# S06. 한 방향 대시만

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 위험 장판/일격이 오면 대시 한 번 |
| 체감 | “피했다!” 직후 슬로우모션 카운터 |
| 쇼츠 길이 | 5~10초 |
| 입력 | 대시 키 1회 (방향은 자동 또는 WASD 순간) |
| 성공 | 회피 성공 → 자동 반격 처형 |
| 실패 | 피격 / 대시 낭비 후 피격 |
| 비주얼 업 | 잔상·슬로우가 티어 트레일과 궁합 |
| 주의 | 판정 윈도우를 읽기 쉽게(예고 이펙트) |
| 우선순위 감 | 높음 |

타겟 고정 연사와 간헐 회피로 조합하는 메모: [S07](s07-target-lock.md). 티어 트레일: [비주얼 티어](../art/visual-tiers.md)
