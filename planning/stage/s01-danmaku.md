# S01. 탄막 피하며 적 죽이기

상태: **기획 메모** — 미구현. [후보 목록](candidates.md)

| 항목 | 메모 |
|------|------|
| 한 줄 | 탄을 피하면서 딜로 적을 정리 |
| 체감 | 회피 액션 + 비주얼 밀도 (특수몹/중간 하이라이트에 적합) |
| 쇼츠 길이 | 일반 12~15초 / 특수 60~90초 가능 |
| 입력 | 이동(WASD) + 공격 유지 |
| 성공 | 전멸 전 적 처치 |
| 실패 | 탄/접촉 누적 데미지 |
| 비주얼 업 | 티어 오라가 “탄막 사이로 돌파”할 때 잘 보임 |
| 주의 | 파티 시 화면 난잡 → 내 탄/남 탄 우선순위·이펙트 캡 필요 |
| 우선순위 감 | 높음 (기존 액션 루프와 가장 자연스럽게 연결) |

비주얼 티어: [비주얼 티어](../art/visual-tiers.md). 이펙트 캡: [연출](../art/presentation.md), [리스크](../concept/risks.md). 파티 규모: [인던 룸](../combat/instance.md).
