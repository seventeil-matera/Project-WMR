# 전투 방 비트표 (프로토타입 v0)

## 일반 방 (목표 10~15초)

| 초 | 서버 | 클라 연출 |
|----|------|-----------|
| 0.0 | 방 스폰, 플레이어 좌측 배치 | 아레나 페이드/그리드 |
| 0.0~2.0 | 몬스터 우측 스폰 후 접근 | 스폰 이벤트 |
| 2.0~12 | 자동 평타 + Q/E | 히트 버스트, 카메라 쉐이크 |
| 클리어 | `room_clear` → 0.3~0.9초 전환 | 그린 링 FX |
| 전환 후 | 다음 방 `spawn` | 즉시 다음 클립 |

티어 업: 방 4/8/12 클리어 시 `tier_up` (T2/T3/T4).

## 특수 방 — 균열의 수호자 (목표 ~90초)

| 구간 | 내용 |
|------|------|
| 오프닝 | 가디언 1 + 애드 4 |
| 페이즈 1 | 가디언 HP > 45% |
| 전환 | HP 45% 이하 → `phase: 2` + 애드 6 추가 스폰 |
| 처치 | 전멸 시 `run_clear` |

## 조작

- WASD / 방향키: 이동
- 자동 평타 (근접 시)
- Q: 원형 참격
- E: 바라보는 방향 돌진 타격
- Space: 평타 수동 트리거
