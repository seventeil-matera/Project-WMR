# 스테이지 컨셉 백로그 (아이디어만 · 미구현)

> 상태: **기획 메모** — 코드/프로토타입 반영 없음.  
> 쇼츠형 던전(10~15초 클립) 안에 끼워 넣을 **방 타입 후보**.

현재 프로토타입 방은 “접근전 + 딜” 단일 타입이다. 아래 4종을 섞으면 클립 리듬이 더 쇼츠답게 변한다.

---

## 1. 탄막 피하며 적 죽이기

| 항목 | 메모 |
|------|------|
| 한 줄 | 탄을 피하면서 딜로 적을 정리 |
| 체감 | 회피 액션 + 비주얼 밀도 (특수몹/중간 하이라이트에 적합) |
| 쇼츠 길이 | 일반 12~15초 / 특수 60~90초 가능 |
| 입력 | 이동(WASD) + 공격 유지 |
| 성공 | 전멸 전 적 처치 |
| 실패 | 탄/접촉 누적 데미지 |
| 비주얼 업 | 티어 오라가 “탄막 사이로 돌파”할 때 잘 보임 |
| 주의 | 파티 시 화면 난잡 → 내 탄/남 탄 우선순위·이펙트 캡 필요 |
| 우선순위 감 | 높음 (기존 액션 루프와 가장 자연스럽게 연결) |

---

## 2. 타이밍 맞춰 버튼 누르기

| 항목 | 메모 |
|------|------|
| 한 줄 | 판정 구간에 맞춰 스킬/확인 키를 누름 (QTE·패리 계열) |
| 체감 | 짧은 긴장 → 성공 시 강한 히트스톱/처형 FX |
| 쇼츠 길이 | 8~12초 (한두 번의 판정으로 끝나는 클립) |
| 입력 | 단일 키(또는 스킬 슬롯) 타이밍 |
| 성공 | Perfect / Good 판정으로 피해·클리어 |
| 실패 | Miss 시 경직·데미지 또는 클립 실패 |
| 비주얼 업 | Perfect 연출이 티어 FX 과시 구간 |
| 주의 | 파티면 전원 동시 QTE vs 대표 1인 — 설계 선택 필요 |
| 우선순위 감 | 중 (구현 단순, 연출 의존도 높음) |

---

## 3. 타이밍 맞춰 좌·우·위·아래 제스처

| 항목 | 메모 |
|------|------|
| 한 줄 | 지시 방향에 맞춰 스와이프/키 방향 입력 |
| 체감 | 리듬 게임형 회피·가드·반격 |
| 쇼츠 길이 | 10~15초, 노트 4~8개 |
| 입력 | ← → ↑ ↓ (키보드) / 스와이프(모바일 대비) |
| 성공 | 시퀀스 통과 → 반격 일격 클리어 |
| 실패 | 잘못된 방향·늦은 입력 |
| 비주얼 업 | 방향 성공마다 짧은 컷인, 마지막에 티어 피니시 |
| 주의 | PC·모바일 입력 매핑을 처음부터 같이 정의 |
| 우선순위 감 | 중 (모바일 “작은 화면” 목표와 궁합) |

---

## 4. 버튼 연타하기

| 항목 | 메모 |
|------|------|
| 한 줄 | 제한 시간 안 연타로 게이지/제압 |
| 체감 | 단순·즉각적, 중간 템포 브레이크용 |
| 쇼츠 길이 | 6~10초 |
| 입력 | 동일 키 연타 (또는 좌클릭 연타) |
| 성공 | 게이지 full → 제압/파괴 |
| 실패 | 시간 초과·게이지 미달 |
| 비주얼 업 | 게이지·충격파가 티어색으로 물듦 |
| 주의 | 연타 피로·손손상 이슈 → 짧은 구간만, 대체 홀드 옵션 검토 |
| 우선순위 감 | 중저 (양산 쉽지만 남발하면 허무) |

---

## 던전 편성 스케치 (미확정)

쇼츠 런 한 판(예: 12+1)에 섞는 예시:

| 슬롯 | 타입 후보 |
|------|-----------|
| 1~3 | 기존 접근전 / 가벼운 탄막 |
| 4 | 타이밍 버튼 |
| 5~7 | 접근전·탄막 |
| 8 | 제스처 방향 |
| 9~11 | 접근전 |
| 12 | 연타 제압 (미니 이벤) |
| 13 특수 | 탄막 + 타이밍 페이즈 |

규칙 초안:

- 한 클립 = **한 가지 주 입력** (섞어도 메인은 하나)
- 실패해도 가능하면 **체크포인트 재도전** (쇼츠 템포 유지)
- 연출 예산은 2·3·특수에 몰고, 1·4는 가볍고 자주

---

## 다음에 정하면 좋은 것 (아직 안 함)

1. 파티(4인)일 때 QTE/제스처/연타를 **개인 판정 vs 공유 게이지** 중 무엇으로 할지  
2. 각 타입의 **Perfect 보상**이 드랍인지 연출만인지  
3. 모바일 제스처·연타 UX 초안  
4. 프로토타입에 넣을 **첫 파일럿 1종** 선택 (추천: 탄막 또는 타이밍 버튼)
