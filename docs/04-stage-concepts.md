# 스테이지 컨셉 백로그 (아이디어만 · 미구현)

> 상태: **기획 메모** — 코드/프로토타입 반영 없음.  
> 쇼츠형 던전(10~15초 클립) 안에 끼워 넣을 **방 타입 후보 전체**.

현재 프로토타입 방은 “접근전 + 딜” 단일 타입이다.  
아래 후보는 **입력은 단순, 성공 순간 연출이 큰** 쇼츠용 조작 모음이다.

## S01. 탄막 피하며 적 죽이기

| 항목 | 메모 |
|------|------|
| 한 줄 | 탄을 피하면서 딜로 적을 정리 |
| 체감 | 회피 액션 + 비주얼 밀도 (특수몹/중간 하이라이트에 적합) |

| 실패 | 탄/접촉 누적 데미지 |

| 우선순위 감 | 높음 (기존 액션 루프와 가장 자연스럽게 연결) |

## 던전 편성 스케치 (미확정)

쇼츠 런 한 판(예: 12+1)에 섞는 예시:

| 슬롯 | 타입 후보 |
|------|-----------|
| 1~3 | S07 또는 가벼운 S01 |
| 4 | S02 또는 S11 |
| 5~6 | S01 |
| 7 | S06 또는 S05 |
| 8 | S03 또는 S09 |
| 9~10 | S01 / S07 |
| 11 | S04 또는 S13 |
| 12 | S10 또는 S14 |
| 13 특수 | S01 탄막 + S08/S02 페이즈 |

규칙 초안:

- 한 클립 = **한 가지 주 입력** (섞어도 메인은 하나)
- 실패해도 가능하면 **체크포인트 재도전** (쇼츠 템포 유지)
- 연출 예산은 하이라이트·특수에 몰고, 메인·브레이크는 가볍고 자주
- 입력 종류는 클립당 **1~2개** , 3초 안에 규칙 이해

## 다음에 정하면 좋은 것 (아직 안 함)

1. 파티(4인)일 때 타이밍/제스처/연타를 **개인 판정 vs 공유 게이지** 중 무엇으로 할지  
2. 각 타입의 **Perfect 보상**이 드랍인지 연출만인지  
3. 모바일 제스처·연타·드래그 UX 초안  
4. 프로토타입 **첫 파일럿 1~2종** 선택 (추천: S01 탄막, S02/S08 타이밍·가드)
