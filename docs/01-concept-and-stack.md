# Web MORPG — 컨셉 & 기술 스택 초안

> 작업 제목: **Mortgage** (가칭)  
> 목표: PC 브라우저 우선 웹 MORPG. 쇼츠형 빠른 전투 + 성장 비주얼 업.

---

## 1. 한 줄 정의

로비에서 모여 파티를 맺고, 던전에 들어가 **10~15초짜리 전투 클립을 10~20회** 이어 플레이하며, 특수 몬스터만 **약 90초** 하이라이트로 싸우는 **비주얼 액션 인스턴스 MORPG**.

---

## 2. 핵심 기둥 (Pillars)

| 기둥 | 플레이 체감 | 제작 규칙 |
|------|-------------|-----------|
| 빠른 템포 | 매칭→클리어→보상→재입장이 끊기지 않음 | 한 던전 체감 5~10분, 방 전환 공백 최소화 |
| 성장 비주얼 업 | 세면 캐릭터가 “달라 보임” | 스탯보다 **외형/오라/스킬 FX 티어**를 먼저 |
| 비주얼 액션 | 타격·처치 연출이 보상 | 일반전은 짧은 한 컷, 특수몹에 연출 예산 몰기 |
| Windows 웹 최적화 | Chrome/Edge 데스크톱 60fps | 품질 프리셋 Low/High, 이펙트 캡 |
| 모바일(후순위) | 작은 화면으로도 조작 가능 | 1차는 UI·입력만, 연출/해상도는 PC 기준 축소 |

---

## 3. 세션 / 월드 구조

```
[로비 샤드] 동시 50~100명
  - 이동, 채팅, 매칭, 상점, 외형 확인
  - 전투·대형 PvP 없음

[인던 룸] 파티 4명 (여유 시 8명)
  - 일반 방 10~18 + 특수 몬스터 1~2
  - 서버 권위 인스턴스, 클리어 후 파괴
```

### 권장 1차 던전 구성

- 일반 방 **12** + 특수 **1**
- 일반 목표 클리어 **10~15초**
- 특수 목표 전투 **60~90초**
- 실패 시: 던전 전체 리셋이 아니라 **체크포인트(직전 클리어 방)**

---

## 4. 전투 루프 (쇼츠형)

### 4.1 일반 방 (한 클립 ≈ 12초)

| 초 | 비트 |
|----|------|
| 0.0~0.5 | 방 진입 / 카메라 고정 |
| 0.5~2.0 | 몬스터 스폰 + 짧은 위협 연출 |
| 2.0~10 | 광역·연계로 정리 (패턴 학습 최소화) |
| 10~12 | 처치 FX → 드롭 연출 → 다음 방 문 오픈 |
| 12~14 | 이동(가능하면 자동 런인 / 짧은 대시) |

**일반 방 원칙**

- “한 컷에 끝나는 액션 쇼츠”
- 패턴 숙련형 금지 (특수몹 전용)
- 파티원 이펙트는 다운스케일, **내 캐릭터·타겟** 연출 우선

### 4.2 특수 몬스터 (≈ 90초)

| 구간 | 내용 |
|------|------|
| 오프닝 ~5초 | 등장·카메라·티어 과시 |
| 페이즈 1 ~35초 | 기본 패턴 2~3개 |
| 페이즈 전환 | 파괴·각성 FX (성장 티어가 돋보이는 구간) |
| 페이즈 2 ~40초 | 강화 패턴 + 파티 역할 한 가지 |
| 처형 ~5초 | 긴 처치 연출 + 보상/티어업 티저 |

---

## 5. 성장 & 비주얼 티어

스탯 성장과 **비주얼 티어**를 분리한다. 플레이어가 느끼는 “성장”의 주인공은 비주얼.

| 티어 | 외형 | 스킬 FX | 오라/트레일 |
|------|------|---------|-------------|
| T1 | 기본 | 단색·짧은 히트 | 없음 |
| T2 | 부위 1~2 교체 | 히트스파크 강화 | 약한 트레일 |
| T3 | 세트 느낌 | 스크린 셰이크·히트스톱 | 오라 ON |
| T4 | 풀세트 + 무기 스킨 | 처형급 피니시 | 풀 오라 |

**파이프라인 규칙**

- 파츠 무한 조합 금지 → **티어 4단 + 직업별 세트**
- 티어업은 **던전 클리어 직후 로비/결과 화면에서 즉시 재생**
- 다음 일반 방 첫 스킬부터 새 FX가 보이게 (쇼츠 중독 포인트)

## 6. 기술 스택 초안

### 6.1 클라이언트 (PC 웹 우선)

| 영역 | 선택 | 이유 |
|------|------|------|
| 언어 | TypeScript | 팀 속도·타입 안전 |
| 번들 | Vite | 빠른 반복, 코드 스플리팅 |
| 렌더 | PixiJS (2D) 또는 Three.js (2.5D/3D) | **1차 추천: PixiJS** — 쇼츠형 이펙트·스프라이트 티어에 적합, 모바일 축소도 쉬움 |
| UI | 게임 오버레이는 경량 DOM/HTML 또는 인캔버스 UI | 로비·상점·매칭은 DOM, 전투 HUD는 캔버스 가능 |
| 입력 | 키보드·마우스 우선, 터치 스틱은 후순위 어댑터 | Windows 웹 최적화 |
| 오디오 | Howler 또는 Web Audio 래퍼 | 짧은 타격음 뱅크 |

**품질 프리셋**

- High: 풀 FX, 파티원 이펙트 100%
- Low: 파티원 FX 30%, 바닥 장판 단순화, 그림자 OFF

### 6.2 서버

| 영역 | 선택 | 이유 |
|------|------|------|
| 런타임 | Node.js (TypeScript) | 클라와 언어 공유, 인던 룸 모델에 충분 |
| 실시간 | WebSocket (uWebSockets / ws) | 브라우저 표준, 인던·로비 분리 연결 가능 |
| 권위 | **서버 권위** 전투 | 데미지·스폰·클리어 판정은 서버 |
| 로비 | 샤드 프로세스 (50~100) | 전투 없음 → 낮은 틱 |
| 인던 | 룸당 프로세스/워커 또는 룸 매니저 내 격리 | 4~8인, 수명 짧음 |
| DB | PostgreSQL | 계정·캐릭·인벤·티어 |
| 캐시/매칭 | Redis | 세션, 매칭 큐, 로비 프레즌스 |
| 호스팅 | 컨테이너 (Fly/GCP/AWS 등) | 인던 수평 확장 |

### 6.3 공유

- 프로토콜 스키마: **MessagePack 또는 JSON** (1차는 JSON, 핫패스만 바이너리 검토)
- 공통 상수: 데미지 공식, 방 템플릿 ID, 티어 테이블을 `shared/` 패키지로

## 7. 아키텍처 개요

```
Browser (Vite + Pixi)
    │  WSS
    ├────────────► Lobby Gateway ──► Lobby Shard (presence, chat, match)
    │                                    │
    │                                    ▼ match ok
    └────────────► Dungeon Gateway ──► Dungeon Room (authority sim)
                                           │
                                           ▼ clear
                                      Reward Service → DB
```

### 틱 / 동기화

| 구간 | 서버 틱 | 클라 |
|------|---------|------|
| 로비 | 5~10 Hz 또는 이벤트 드리븐 | 보간 거의 불필요 |
| 일반 방 | 15~20 Hz | 입력 전송 + 스냅샷 보간 |
| 특수몹 | 20 Hz | 동일 + 연출은 클라 예측(이펙트만) |

**원칙**

- 이동·스킬 **요청은 클라**, **히트·사망·클리어는 서버**
- 이펙트·히트스톱·카메라 셰이크는 클라 전용 (서버는 “이벤트 타입”만 통지)
- 일반 15초 방은 동기화 오차가 쌓일 시간이 짧아 웹에 유리

### 네트워크 메시지 (최소 세트)

- `lobby.join` / `lobby.chat` / `match.queue` / `match.ready`
- `dungeon.enter` / `input.frame` / `skill.cast`
- `snapshot` / `event.spawn|hit|kill|clear|tier_up`
- `reward.summary`

## 8. 콘텐츠 파이프라인

1. **방 템플릿** 소수 (직선 아레나, 원형, 복도형 등 3~4종)
2. **몬스터 스킨 + 체력/위협 테이블**로 일반 방 양산
3. **특수몹**만 전용 패턴·페이즈·연출 스크립트
4. **비주얼 티어 팩** (직업×티어) — 스프라이트/VFX 아틀라스
5. 데이터는 JSON/YAML → 빌드 시 검증 후 서버·클라 공유

---

## 9. MVP (출시 단위) 범위

### 포함한다

- 계정 + 캐릭 1슬롯
- 직업 **2**
- 로비 1샤드 (이동·채팅·매칭·외형)
- 던전 **1** (일반 12 + 특수 1)
- 파티 **4인**
- 비주얼 티어 **T1~T4**
- PC Chrome/Edge, 품질 Low/High
- 결과 화면 + 즉시 재도전

### 제외한다 (Non-goals)

- 오픈월드 / 로비 대규모 전투
- 복잡 경제·거래소 전체
- 하우징, 생활 콘텐츠 풀셋
- 8인 레이드 완성도
- 모바일 동등 품질 (터치 UI 실험만 허용)

## 13. 프로토타입 현황 (구현됨)

- `apps/client` + `apps/server` + `packages/shared` 모노레포
- 솔로 권위 시뮬: 일반 12 + 특수 1, 티어 T1~T4, Q/E/자동평타
- 실행: `npm install && npm run build -w @wmr/shared && npm run dev:server` / `npm run dev:client`
- 스모크: 서버 켠 뒤 `npm run smoke` (헤드리스 풀클리어)
